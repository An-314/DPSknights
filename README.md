# DPSknights · 纵横

《明日方舟》非官方干员伤害计算器。可设置干员练度、敌方防御与法抗、肉鸽藏品和生效条件，查看逐击伤害、元素损伤积累、治疗与回费，并在同一场景下比较多个方案。

[打开计算器](https://an-314.github.io/DPSknights/)

## 站点与依赖

本仓库保存可直接部署的静态版本。浏览器在本地执行模拟，方案保存在访问者的浏览器中。可通过 GitHub Pages 从 `main` 分支的根目录发布，也可将同一组文件托管在其他静态服务器。

React、React DOM、Scheduler、Apache ECharts、ZRender、Lucide React 和 tslib 随站点提供。访问时无需安装游戏或运行其他服务。[第三方软件声明与许可证](THIRD-PARTY-NOTICES.txt)

页面默认使用占位图。可在页顶选择「本机贴图」，打开含 `avatars` 和 `is-icons` 的本地图像目录。图片只保存在当前浏览器，清除后恢复占位图。

游戏名称及相关权益归相应权利人。参数来自国服游戏数据和公开版本快照，模型另参考 PRTS 与 tomimi.dev 的机制研究。[明日方舟官网](https://ak.hypergryph.com/) · [游戏数据镜像](https://github.com/Kengxxiao/ArknightsGameData) · [PRTS](https://prts.wiki/) · [tomimi.dev](https://tomimi.dev/)
